# AI Code Review Agent - Demo Repository

This repository demonstrates the AI-Powered Code Review Assistant in action.

## What This Shows

The `feature-bad-code` branch contains deliberately buggy code. A pull request is open from `feature-bad-code` to `main`. An AI agent automatically reviews the code and posts comments classifying issues as Critical, Moderate, and Minor.

## The Pull Request

Check the **Pull Requests** tab to see the bot's review comments.
